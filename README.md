# PingQuantumly
## About
**PingQuantumly** is an Internet Speed Testing application that measures your download and upload speed efficiently. Built using **Java Swing**, it provides a simple yet effective UI for users to analyze their network performance.

## 🚀 Features

- 📶 **Download Speed Test** - Accurately measures how fast data is downloaded from the internet.
- 🚀 **Upload Speed Test** - Determines the speed of data uploaded to the internet.
- 📊 **Live Speed Meter** - Displays real-time speed fluctuations.
- 🎨 **User-Friendly Interface** - Simple and easy-to-use Java Swing UI.
- 📁 **Standalone Application** - Available as a JAR file for quick execution.

## 🔧 Installation & Usage

1. **Download the JAR file** from the link above.
2. **Run the application** using the following command:
   ```bash
   java -jar InternetSpeed.jar
   ```
3. **Start testing** your internet speed with a simple and intuitive interface!

## 🛠️ Technologies Used

- **Java** (Core functionality)
- **Java Swing** (GUI framework)
- **Networking API** (For speed calculations)
